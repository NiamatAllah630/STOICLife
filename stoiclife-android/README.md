# STOICLife Android

Ce dossier contient le code source complet de l'application mobile STOICLife développée sous Android Studio.

Technologies utilisées :
- Java
- Android SDK
- SQLite

Fonctionnalités principales :
- Authentification utilisateur
- Gestion du planning quotidien
- Activités stoïciennes
- Journal personnel
- Suivi émotionnel
- Système XP, niveaux et badges
- Citations stoïciennes
- Mode Focus
